# Security Policy

## Official Access Point
**Grodus Wallet** operates strictly inside Telegram via the official bot:
* **Official Bot URL:** [https://t.me](https://t.me)
* **Official Username:** `@GrodusWalletBot`

## Anti-Phishing Guidelines
1. Always verify the exact username `@GrodusWalletBot` before initiating any transactions.
2. Grodus Wallet has **no external web interfaces**, browser extensions, or standalone APK/IPA files.
3. Official administrators and support agents will never initiate direct messages or ask for your account credentials.

## Reporting a Vulnerability
If you discover a security issue or a phishing clone impersonating Grodus Wallet, please contact our team through the official support menu inside [@GrodusWalletBot](https://t.me).
