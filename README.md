# Grodus Wallet — Мультичейн криптокошелек в Telegram

**Grodus Wallet** (`@GrodusWalletBot`) — это кастодиальный мультивалютный криптокошелек, встроенный в интерфейс мессенджера Telegram. Сервис позволяет безопасно хранить, отправлять и получать популярные криптовалюты и стейблкоины без установки сторонних приложений и браузерных расширений.

🚀 **Запустить кошелек в Telegram:** [t.me/GrodusWalletBot](https://t.me/GrodusWalletBot)

## Поддерживаемые сети и монеты

Grodus Wallet работает с шестью популярными блокчейнами, обеспечивая быстрые переводы и выбор оптимальной сети по размеру комиссии:

| Блокчейн (Сеть) | Нативный токен | Поддержка стейблкоинов |
| :--- | :--- | :--- |
| **TON (The Open Network)** | TON | USDT (TON) |
| **TRON** | TRX | USDT (TRC-20) |
| **Solana** | SOL | USDT (SOL) |

| **BNB Chain** | BNB | USDT (BEP-20) |
| **Polygon** | POL (MATIC) | USDT (Polygon) |

## Преимущества Grodus Wallet

* **Работает внутри Telegram.** Весь функционал доступен сразу после запуска бота [@GrodusWalletBot](https://t.me/GrodusWalletBot) на любом устройстве (iOS, Android, Desktop, Web).
* **Единый мультичейн-интерфейс.** Управление активами в сетях TON, TRON, Solana, Ethereum, BNB Chain и Polygon из одного меню.
* **Быстрый старт без seed-фраз.** Кастодиальная архитектура избавляет от необходимости вручную записывать длинные мнемонические фразы и настраивать сети.
* **Удобная работа с USDT.** Поддержка ввода и вывода Tether (USDT) во всех основных сетях.

## Часто задаваемые вопросы (FAQ)

### Как открыть Grodus Wallet?
Перейдите по официальной ссылке [https://t.me/GrodusWalletBot](https://t.me/GrodusWalletBot) или найдите `@GrodusWalletBot` через поиск в Telegram и нажмите кнопку «Запустить» (Start).

### Какие криптовалюты поддерживает Grodus Wallet?
Кошелек поддерживает нативные монеты TON, TRX, SOL, ETH, BNB, POL (MATIC), а также стейблкоин USDT в соответствующих сетях.

### Есть ли у Grodus Wallet отдельный сайт или приложение?
Нет, Grodus Wallet функционирует исключительно в экосистеме Telegram через официального бота `@GrodusWalletBot`.
